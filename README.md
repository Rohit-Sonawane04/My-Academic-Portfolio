# Academic Project

## Objective
The main goal of this project is to make a simple and clean website for Akshnil Computer Institute. It helps students see all the available computer courses, checking the lab facilities, and contact the institute easily.

## Description Of The Project
This is a basic website project for a computer training center. It shows information about different courses like Tally, Graphic Design, and Web Development. It also includes a gallery, student reviews, and a simple contact form.

## Languages and Tools Used

| Attribute |   Details |
| :--- | :--- |
| **Languages** | HTML, CSS, JavaScript |
| **Code Editor** | VS Code or Notepad++ |
| **Web Browser** | Google Chrome or any browser |

## Steps to Execute The Program
Follow these easy steps to run the project:

1. **Download:** Save the project files on your computer.
2. **Open Folder:** Open the folder where you saved the files.
3. **Find Index File:** Look for the file named `index.html`.
4. **Run:** Double-click on `index.html` to open it in your Google Chrome or any web browser.
